# Topçam Güvenlik Sistemleri Web Sitesi

Modern, yüksek performanslı ve kurumsal güvenlik sistemleri web platformu.

## 🚀 Teknolojik Altyapı
- **Framework:** Next.js 16.4.3 (App Router & Turbopack)
- **Kütüphane:** React 19.2.4
- **Stil & Tasarım:** Tailwind CSS v4, tw-animate-css
- **Tipografi:** Google Fonts - IBM Plex Sans
- **İkonlar:** Lucide React & Optimize Edilmiş Vektörler
- **Görseller:** WebP optimize edilmiş formatlar
- **Güvenlik Başlıkları:** CSP, HSTS, X-Frame-Options, No-Sniff, Referrer-Policy, Rate Limiting & Honeypot
